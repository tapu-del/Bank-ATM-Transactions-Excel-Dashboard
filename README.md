# 🏧 Bank ATM Transactions Dashboard

## About the Project
This project is an interactive Excel dashboard built to analyze bank ATM transaction data. The goal was to track cash flow, identify peak transaction types, and analyze usage across different location types.

## Tools & Skills Used
* Microsoft Excel
* Data Cleaning & Preparation
* PivotTables & PivotCharts
* Interactive Slicers
* Dashboard Design

## Key Metrics Analyzed
* **Transaction Types:** Analyzed Cash Withdrawals vs. Balance Enquiries vs. Deposits.
* **Location Analysis:** Used a Slicer to filter data by Urban, Semi-Urban, and Rural areas.
* **Financial Impact:** Calculated the total Amount (Sum) for each transaction type.
